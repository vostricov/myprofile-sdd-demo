# Don't Scenario Demo

This branch is intentionally structured as a negative example for pull request
review training.

Reviewers should be able to spot these problems:

- Commit subjects are vague and do not follow the repository policy.
- The commits do not explain scope, intent, or task linkage.
- The PR description is too short to evaluate risk or behavior.
- Validation is missing, ambiguous, or unverifiable.
- The branch forces reviewers to infer what changed instead of stating it.

Do not use this branch as an implementation example. Its purpose is to make
poor contribution hygiene easy to recognize.
