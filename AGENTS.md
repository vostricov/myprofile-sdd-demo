## Implementation Branch Policy

Before implementing a task from `tasks.md`, create or switch to a dedicated
branch for that task. Branch names MUST start with `feature/` and SHOULD include
the task ID and short slug, for example `feature/t001-scaffold-frontend`.
Keep each task branch scoped to one task and mark only that task `[X]` after its
acceptance criteria are verified.
